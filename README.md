# Сұңқар Балабақшасы — сайт детского сада

Next.js 15 (App Router), TypeScript, Tailwind CSS v4, Lucide. База данных и регистрация не нужны.

- `/` — казахская версия (основная), `/ru` — русская.
- Компьютер: `src/components/website/`. Телефон: `src/components/mobile-website/`. Общее: `src/components/shared/`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # проверка production-сборки
npm run typecheck
npm run lint
```

## Где что менять

| Что | Где |
| --- | --- |
| Адрес, телефон, часы работы, карта, ссылка на документы | `src/components/shared/config.ts` |
| Все тексты на двух языках, названия групп | `src/components/shared/i18n.ts` |
| Цвета, шрифты, анимации | `src/app/globals.css` |

**Документы.** Вставьте ссылку Google Drive в `documentsUrl` в `config.ts`. Кнопка станет активной, а надпись «Жақында қолжетімді болады» исчезнет.

## Фотографии

Сейчас в проекте **нет настоящих фотографий**: на их месте стоят иллюстрации с подписью. Фото из 2ГИС не скачаны, потому что разрешение на их использование не подтверждено.

Положите файлы в `public/images/` и пересоберите сайт. Менять код не нужно.

| Файл | Куда попадает |
| --- | --- |
| `main-page.jpg` | Главное фото на первом экране |
| `hero2.jpg`, `hero3.jpg` | Маленькие фото рядом с главным (только на компьютере) |
| `main-page2.jpg` или `main-page2.mp4` / `.webm` | Фото или видео в разделе «О нас» |
| `image1.jpg`, `image2.jpg`, … | Галерея, в порядке номеров, без ограничения количества |
| `logo.png` | Логотип вместо текстового знака с соколом |

- Подходят форматы png, jpg, webp, avif. HEIC с iPhone сначала сохраните как JPG.
- Рекомендуемая длинная сторона: до 2000 px. Next.js сам уменьшает и сжимает изображения.
- В галерее фото показываются целиком, без обрезки. На главном экране рамка фигурная: если важная часть попала за край, поправьте `heroFocus` в `config.ts`.
- Если главное фото загружено, подпись про иллюстрацию исчезает автоматически.
- **Публикуйте фотографии детей только с согласия родителей.**

## Публикация на Vercel

1. Загрузите проект в репозиторий и импортируйте его в Vercel. Настройки сборки менять не нужно.
2. Адрес сайта для SEO определится автоматически.

### Домен edu.kz

1. Добавьте домен в Vercel: Project → Settings → Domains.
2. Настройте DNS-записи у регистратора, как покажет Vercel.
3. Укажите в Vercel переменную `NEXT_PUBLIC_SITE_URL=https://ваш-домен.edu.kz` и запустите пересборку. Canonical, hreflang и sitemap обновятся сами.

## Что проверить перед запуском

- **Часы работы.** На сайте указано 07:00–18:30, а в карточке 2ГИС и во всплывающем окне карты — 08:00–18:00. Владелец может исправить данные в 2ГИС.
- **Группы.** Названия и возрастное деление предварительные.
- **Казахские тексты.** Проверены только автоматически и при чтении: перед публикацией стоит показать их носителю языка.
